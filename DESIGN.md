# Design system

## Direction

A contemporary office register: a calm, paper-toned working surface with the order and legibility of a well-kept business ledger. Use clear columns, fine rules, measured spacing, and restrained serif headings over practical sans-serif interface text.

## Palette

- Paper background: `#F3F1E9`
- Primary surface: `#FFFEFA`
- Muted surface: `#EAE7DC`
- Ink: `#252921`
- Secondary text: `#62665C`
- Rules: `#D6D2C5`
- Forest accent: `#31543D`
- Forest deep: `#243E2D`
- Ochre state: `#76551C`
- Clay state: `#8A3E32`

No gradients, blue, or purple. Reserve forest for primary actions and active work, ochre for new tasks, and clay for failed tasks and errors.

## Type

Use a system sans-serif for controls, forms, and dense content. Use Georgia with a serif fallback for prominent headings. Keep task names and form labels compact and readable.

## Components

- Use warm white panels, fine neutral borders, modest corner rounding, and subtle offset shadows.
- Forms share the same label, input, focus, error, and submit-button treatment.
- Tables use real column headers, quiet row dividers, and aligned tabular counts.
- Task cards use consistent surfaces with restrained status labels; status actions remain prominent and keyboard accessible.
- Responsive forms stack on narrow screens and form two columns on wide screens; task cards remain horizontally navigable on small screens.

## Scope

This visual system covers sign-in, admin, and employee surfaces. It changes presentation only; existing features, copy meaning, and workflows remain intact.
